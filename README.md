## Project Overview
This project focuses on transforming raw e-commerce data into meaningful visualisations using Python and Tableau. The objective is to analyse sales trends, product category performance, customer payment preferences and seller performance through charts and an interactive dashboard.

## Dataset
**Source:** [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)  
**Files:** 9 CSV files covering customers, orders, products, payments, sellers, reviews and other information.  
**License:** CC BY-NC-SA 4.0.

The original dataset is not included in this repository. It can be downloaded from the Kaggle source.

## Objectives
- Analyse e-commerce sales and business performance.
- Visualise monthly revenue and order trends.
- Identify top-performing product categories.
- Understand customer payment preferences.
- Compare seller performance based on revenue.
- Present business insights through visualisations and a dashboard.

## Business Questions Answered
1. How does revenue change month by month?
2. How does the number of orders vary over time?
3. Which product categories generate the highest revenue?
4. Which payment methods are most commonly used?
5. Which sellers generate the highest revenue?

## Data Preparation & Visualization
- Loaded and prepared nine datasets using Pandas.
- Checked data types, missing values and duplicates.
- Combined and processed relevant datasets.
- Created summary CSV files for Tableau.
- Developed charts to analyse sales, orders, categories, payments and seller performance.
- Designed an E-Commerce Sales & Business Performance Dashboard in Tableau.

## Visualisations Created
- Monthly E-Commerce Sales Trend
- Monthly Orders Analysis
- Category Sales Analysis
- Payment Summary
- Top Sellers by Revenue

## Key Insights
The visualisations help identify:
- Monthly patterns and changes in revenue and order volume.
- Product categories contributing the highest revenue.
- Customer preferences for different payment methods.
- Sellers generating the highest revenue.

These insights can support better understanding of e-commerce business performance and data-driven decision-making.
